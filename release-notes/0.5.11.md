# Lyricod 0.5.11

这次更新让音译跟着演唱逐字高亮，并大幅降低了 Lyricod Glass 液态玻璃效果在画面静止时的占用✨

### 更新内容

- **音译逐字高亮**：QQ 音乐的罗马音带有逐字时间，现在歌词岛、桌面歌词和歌词窗口中的音译会随演唱逐字高亮，与上方的歌词同步。其他来源的音译，以及 Lyricod 自动生成的音译，显示方式不变。
- **按词分隔罗马音（实验性）**：使用 QQ 音乐的罗马音时，会根据逐字时间按词分隔，即使读音与 Windows 的分析结果不同也能正确对应。
- **液态玻璃**：歌词岛后方的画面没有变化时，液态玻璃不再重复绘制，暂停播放或画面静止时的 CPU 和 GPU 占用明显降低；帧率会跟随「动画」设置。液态效果启动时会先显示透明玻璃，再淡入，不再突然切换。如果 Windows 中断了屏幕捕获，液态效果会自动恢复。
- **歌词岛**：下一句歌词更长时，新歌词会在歌词岛变宽的过程中更早出现。展开或收起迷你播放器时，圆角会随高度平滑变化。屏幕分辨率、缩放比例或显示器变化后，歌词岛会回到原来的位置。
- **歌词窗口**：切换歌曲时，新的歌词会淡入显示。
- **错误日志**：出现问题时，相关信息会记录在 `%LOCALAPPDATA%\Lyricod\lyricod.log` 中，反馈问题时可以附上这个文件。

### 下载

- **Lyricod-0.5.11-windows-x64-setup.exe**：适用于大多数 Intel 和 AMD 处理器的 Windows 电脑。
- **Lyricod-0.5.11-windows-arm64-setup.exe**：适用于 ARM 架构的 Windows 电脑。
- **Lyricod-0.5.11-windows-x64.zip / Lyricod-0.5.11-windows-arm64.zip**：免安装版本，解压后运行 `Lyricod.exe`，并确保 `app` 文件夹与其位于同一目录。

更新时会保留现有设置和已缓存的歌词。Lyricod 支持应用内更新。

如果从免安装版切换到安装版，且此前启用了开机启动，请在「设置 > 通用」中关闭后重新开启。

**系统要求**：Windows 10 1809 或更新版本。音乐律动条和 Lyricod Glass 的液态效果需要 Windows 11；在 Windows 10 上，Lyricod Glass 会使用清透玻璃效果。独立录屏会话的窗口排除功能需要 Windows 11 Build 26100 或更新版本，并取决于系统运行时接口是否可用。

Lyricod 目前尚未进行代码签名，首次运行时 Windows 可能显示安全提示。

This update lights up the pronunciation as it's sung, and makes the Lyricod Glass liquid effect much lighter while the screen behind the island stays still.

### What's changed

- **Pronunciation lit as it's sung**: QQ Music's romaji comes timed word by word, so the pronunciation now lights up syllable by syllable in step with the lyric above it, on the island, in desktop lyrics and in the lyrics window. Pronunciation from other sources, and pronunciation Lyricod works out itself, shows as before.
- **Romaji by word (experimental)**: With QQ Music's romaji, words are now grouped by their timing, so they line up even where Windows reads a word differently.
- **Liquid glass**: The liquid effect only redraws when what's behind the island changes, so it uses much less CPU and GPU while paused or when the screen is still. Its frame rate now follows the Animation setting. It starts as clear glass and fades in instead of switching suddenly, and if Windows stops the screen capture, it comes back on its own.
- **Island**: When the next line is longer, its text appears sooner while the island widens. The mini player's corners change smoothly as it opens and closes. After the resolution, scaling or displays change, the island goes back to its place.
- **Lyrics window**: New lyrics fade in when the song changes.
- **Error log**: Problems are written to `%LOCALAPPDATA%\Lyricod\lyricod.log`. You can attach this file when reporting an issue.

### Download

- **Lyricod-0.5.11-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.5.11-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.5.11-windows-x64.zip / Lyricod-0.5.11-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
