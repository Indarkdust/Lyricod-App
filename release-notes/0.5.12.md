# Lyricod 0.5.12

这次更新为歌词窗口加入了「扫过并浮起」效果，滚动浏览时其他歌词也会变清晰；Lyricod 生成的音译现在也会跟着演唱逐字高亮✨

### 更新内容

- **扫过并浮起**：「设置 > 歌词窗口 > 已唱歌词」新增「扫过并浮起」。颜色照常扫过，正在唱的字词会轻轻浮起并略微放大，唱过后保持浮起并带有柔和的光，下一句开始时整行一起落下。没有逐字时间的歌词仍按原来的方式扫过。
- **滚动浏览歌词**：在歌词窗口中用滚轮、触控板或手指滚动时，其他歌词会取消模糊并稍微变亮，方便阅读；窗口会停在你滚动到的位置，换行时不再跳回。停止滚动 3 秒后，或点击某一句歌词时，模糊恢复，窗口平滑回到正在唱的歌词。
- **音译逐字高亮**：只要歌词带有逐字时间，Lyricod 生成的音译（拼音、日语罗马音、韩语罗马字）也会随演唱逐字高亮，与上方的歌词同步。开启「按词分隔罗马音」时，歌词来源自带但没有逐字时间的罗马音也会高亮。

### 下载

- **Lyricod-0.5.12-windows-x64-setup.exe**：适用于大多数 Intel 和 AMD 处理器的 Windows 电脑。
- **Lyricod-0.5.12-windows-arm64-setup.exe**：适用于 ARM 架构的 Windows 电脑。
- **Lyricod-0.5.12-windows-x64.zip / Lyricod-0.5.12-windows-arm64.zip**：免安装版本，解压后运行 `Lyricod.exe`，并确保 `app` 文件夹与其位于同一目录。

更新时会保留现有设置和已缓存的歌词。Lyricod 支持应用内更新。

如果从免安装版切换到安装版，且此前启用了开机启动，请在「设置 > 通用」中关闭后重新开启。

**系统要求**：Windows 10 1809 或更新版本。音乐律动条和 Lyricod Glass 的液态效果需要 Windows 11；在 Windows 10 上，Lyricod Glass 会使用清透玻璃效果。独立录屏会话的窗口排除功能需要 Windows 11 Build 26100 或更新版本，并取决于系统运行时接口是否可用。

Lyricod 目前尚未进行代码签名，首次运行时 Windows 可能显示安全提示。

This update adds "Sweep with a lift" to the lyrics window, keeps the other lines readable while you scroll through the lyrics, and lights up the pronunciation Lyricod works out as it's sung.

### What's changed

- **Sweep with a lift**: A new choice under Settings > Lyrics window > Sung lyrics. The colour sweeps as before, and each word rises a little and grows slightly as it's sung, stays up with a soft glow once sung, and the line's words come down together when the next line starts. Lines without word timing sweep as before.
- **Scrolling through the lyrics**: When you scroll the lyrics window with a mouse wheel, touchpad or finger, the other lines lose their blur and brighten a little so they're easy to read, and the window stays where you scrolled instead of jumping back at the next line. Three seconds after you stop, or when you pick a line, the blur comes back and the window glides back to the line being sung.
- **Pronunciation lit as it's sung**: Wherever the lyrics are timed word by word, the pronunciation Lyricod works out (pinyin, romaji, romanised Korean) now lights up in step with the line above it. With Romaji by word on, a source's untimed romaji lights up too.

### Download

- **Lyricod-0.5.12-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.5.12-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.5.12-windows-x64.zip / Lyricod-0.5.12-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
