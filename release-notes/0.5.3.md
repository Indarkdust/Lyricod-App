# Lyricod 0.5.3

This update improves NetEase Cloud Music sync.

- **Existing setups are recognised**: Settings > General > NetEase Cloud Music sync now finds BetterNCM and InfLink-rs however they were installed, including InfLink-rs from BetterNCM's plugin store.
- **Shows when it's working**: while NetEase Cloud Music is playing and sharing its playback position, the section says sync is working.
- **No duplicate plugin**: installing replaces an InfLink-rs copy from BetterNCM's plugin store instead of adding a second one, and Remove deletes it too.

### Download

- **Lyricod-0.5.3-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.3-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.3-windows-x64.zip** / **Lyricod-0.5.3-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
