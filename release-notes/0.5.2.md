# Lyricod 0.5.2

This update makes it easier to keep NetEase Cloud Music lyrics in sync, and gives Lyricod Glass clearer defaults.

- **NetEase Cloud Music sync**: set up BetterNCM and InfLink-rs from Settings > General > NetEase Cloud Music sync, so lyrics stay in sync after pausing or seeking. Lyricod downloads a small helper only when you choose to install, and verifies the downloaded files before installation. This supports 64-bit NetEase Cloud Music 3.x. The tray panel's tip about drifting lyrics now opens this setting.
- **Lyricod Glass**: new setups start at 90% transparency with a 10% blur, for clearer glass. Your current settings are kept.
- **Diagnostics**: no longer shows the previous song's cover size.

### Download

- **Lyricod-0.5.2-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.2-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.2-windows-x64.zip** / **Lyricod-0.5.2-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
