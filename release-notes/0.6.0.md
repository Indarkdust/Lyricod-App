### 更新内容

- **新图标**：Lyricod 换上了新图标。现在应该一眼就能看出来了！
- **霞鹜文楷**：「设置 > 通用 > 字体」新增「霞鹜文楷 Lite」。这是一款开源的楷体风格字体，适合中文和日文假名；选择后点击「下载」即可从 GitHub 获取（约 14 MB）。Lite 版不含韩文，韩文歌词会改用其他字体显示。下载过的字体（MiSans 和霞鹜文楷）现在集中在字体下方的「已下载的字体」中，可以查看各自的大小并单独移除。
- **立体效果**：「设置 > 歌词岛 > Lyricod Glass 设置 > 立体效果」现在可以选择「关」「明亮」或「柔和」。「明亮」就是之前的效果，边缘有清晰的高光，在内容丰富的背景上更有厚度感；新的「柔和」高光较淡，背光一侧带有阴影，在纯色背景上边缘依然清楚。悬浮歌词岛下方的阴影也会随之变化。之前开启了立体效果的，更新后自动调整为「明亮」。
- **平滑扫过（实验性）**：「设置 > 关于 > 实验性功能」新增「平滑扫过」。长音后面紧跟短音时，已唱颜色会移动得更均匀，不会先慢后突然加快；短音可能稍微提前亮起，颜色边缘也更柔和。「按词分隔罗马音」也移到了这里，诊断信息会显示开启了哪些实验性功能。
- **更新下载**：应用内更新的下载中断后，不会再从头开始，而是从中断处继续；连接断开或卡住时也会自动重试几次。从下一个版本开始，免安装版和安装版更新时都只需下载有变化的文件，无法使用时会自动改为下载完整文件。下载完成后都会先校验文件再使用。
- **安装程序**：安装时会自动关闭正在运行的 Lyricod；安装失败时会恢复原来的版本。
- **网易云音乐歌词同步**：已在网易云音乐 3.1.43 上测试。(真的)
- **杂项**：悄悄删了一点东西...🤫

This update brings a new app icon and more ways to make Lyricod your own: the LXGW WenKai font, a softer 3D effect for Lyricod Glass, and an experimental smoother lyrics sweep.

In-app update downloads can now resume where they left off if interrupted (yes, I just wished this feature into existence😇).

### What's changed

- **New icon**: Lyricod has a new icon. Hopefully you can tell what it is at a glance now!
- **LXGW WenKai**: Settings > General > Font now offers LXGW WenKai Lite, an open-source font in a handwritten Kai style for Chinese and Japanese kana. Choose it and click Download to get it from GitHub (about 14 MB). The Lite version doesn't include Korean, so Korean lyrics will use another font. Downloaded fonts (MiSans and LXGW WenKai) are now grouped under Downloaded fonts below the font list, where you can see their sizes and remove them individually.
- **3D effect**: Settings > Lyricod Island > Lyricod Glass options > 3D effect now offers Off, Bright, and Soft. Bright is the previous look, with a distinct highlight along the edge that gives the glass more depth against busy backgrounds. The new Soft option has a subtler highlight and a shadow along the opposite edge, keeping the glass visible even against plain backgrounds. The shadow beneath the floating island also changes to match. If you previously had the 3D effect enabled, it will automatically be set to Bright after updating.
- **Smooth sweep (experimental)**: A new Smooth sweep option under Settings > About > Experimental features. When a long note is followed by quick ones, the sung highlight moves more evenly instead of crawling and then suddenly speeding up. Short words may light up slightly early, and the edge of the highlight is softer. Romaji by word has also moved here, and Diagnostics now shows which experimental features are enabled.
- **Update downloads**: Interrupted downloads now resume from where they stopped instead of starting over. Lyricod also retries automatically when a connection drops or stalls. Starting with the next release, both portable and installed versions will download only the files that changed, falling back to the full download whenever a patch can't be used. All downloaded files are verified before use.
- **Installer**: Setup now closes a running Lyricod by itself, and puts the previous version back if installing fails.
- **NetEase Cloud Music sync**: Tested with NetEase Cloud Music 3.1.43. (Really.)
- **Miscellaneous**: Quietly removed a few things... 🤫

### Download

- **Lyricod-0.6.0-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.6.0-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.6.0-windows-x64.zip / Lyricod-0.6.0-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
