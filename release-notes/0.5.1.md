# Lyricod 0.5.1

This update lets screenshots include the Lyricod Glass island and makes album covers show up more reliably.

- **Screenshots with Lyricod Glass**: while the liquid effect is on, the island doesn't appear in screenshots. To include it, click "Show in screenshots" in Settings > Lyricod Island > Lyricod Glass options, then take your screenshot within 10 seconds.
- **Album covers**: if a player sends the cover late, Lyricod now asks for it again 20 seconds into the song.

### Download

- **Lyricod-0.5.1-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.1-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.1-windows-x64.zip** / **Lyricod-0.5.1-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
