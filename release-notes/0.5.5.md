# Lyricod 0.5.5

This update reorganises the Lyricod Island settings and gives new setups better defaults.

- **Lyricod Island settings**: Settings > Lyricod Island now starts with Style (theme, Lyricod Glass options, size and colours), followed by Position and behaviour, then Text.
- **New defaults**: on Windows 11, new setups start with the Lyricod Glass theme; elsewhere they start with the classic island. Moving onto the island now hides it by default, and moving across it then down opens the mini player. Your current settings are kept.

### Download

- **Lyricod-0.5.5-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.5-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.5-windows-x64.zip** / **Lyricod-0.5.5-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
