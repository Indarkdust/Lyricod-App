Lyricod now updates itself.

- **Updates inside Lyricod.** When a new version is out, choose **Download and Install** in Settings › About, or the update link in the tray panel. Lyricod downloads the right file for your PC, checks it against the checksum GitHub publishes for it, then closes and opens again on the new version, with your settings and saved lyrics kept. This works whether you installed Lyricod or use the zip. Lyricod still looks for new versions once a day, and you can turn that off in Settings › About.
- **Nothing old left behind.** After an update, the previous version's files are removed, including the downloaded update itself. Installing a new version over an older one also clears out files the new version no longer uses.
- Getting this version from 0.3.0 or earlier is done by hand one last time; from here on, Lyricod updates itself.

### Download

- **Lyricod-0.3.1-windows-x64-setup.exe**: the installer, for most Windows PCs (Intel and AMD).
- **Lyricod-0.3.1-windows-arm64-setup.exe**: the installer, for Arm PCs (Snapdragon, Copilot+ PCs).
- **Lyricod-0.3.1-windows-x64.zip** and **Lyricod-0.3.1-windows-arm64.zip**: the same, without installing. Unzip it anywhere and run `Lyricod.exe` in the Lyricod folder, keeping the `app` folder next to it.

Lyricod lives in the notification area. Your settings and saved lyrics are kept whichever you choose. To update from 0.3.0 or earlier, quit Lyricod, then replace its whole folder with the new one, or run the installer. If you move from the zip to the installer and had Open at login on, turn it off and on again in Settings › General. It needs Windows 10 (version 1809) or later; the island's bars follow the music on Windows 11. Lyricod isn't signed yet, so Windows may warn the first time: choose **More info › Run anyway**.
