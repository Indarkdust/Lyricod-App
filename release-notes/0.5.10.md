# Lyricod 0.5.10

This update looks for lyrics on the platform you're listening on first, and keeps that platform's translation when the word-by-word lyrics come from the other one.

- **Your player's lyrics first**: playing in NetEase Cloud Music or QQ Music, Lyricod now looks for that platform's lyrics before the others. Other players still start with NetEase Cloud Music.
- **Word by word, with the translation you know**: when one platform has a song line by line and the other has it word by word, Lyricod now shows the word-by-word lyrics with the first platform's translation, instead of picking one or the other. ヨルシカ's 都落ち in NetEase Cloud Music, for example, now lights up word by word with NetEase's translation. Songs you've played before keep their saved lyrics until you choose Search again in Settings > Lyrics > Current song.
- **Diagnostics**: Settings > About > Diagnostics says where the translation came from when it's from the other platform.

### Download

- **Lyricod-0.5.10-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.10-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.10-windows-x64.zip** / **Lyricod-0.5.10-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Session-specific capture exclusion requires Windows 11 build 26100 or newer and runtime interface availability. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
