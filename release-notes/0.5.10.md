# Lyricod 0.5.10

这次更新会优先从你正在使用的播放平台查找歌词，并在使用另一个平台的逐字歌词时保留该平台的翻译。

### 更新内容

- **优先当前平台**：使用网易云音乐或 QQ 音乐播放时，Lyricod 现在会优先查找该平台的歌词。其他播放器仍会优先查找网易云音乐。
- **逐字歌词与翻译**：如果一个平台只有逐行歌词，而另一个平台有同一首歌的逐字歌词，Lyricod 现在会显示逐字歌词，同时保留优先平台的翻译，不再只能二选一。之前播放过的歌曲会继续使用已缓存的歌词，可在「设置 > 歌词 > 当前歌曲」中点击「重新搜索」更新。
- **诊断信息**：翻译来自另一个平台时，「设置 > 关于 > 诊断信息」会显示翻译的来源。

### 下载

- **Lyricod-0.5.10-windows-x64-setup.exe**：适用于大多数 Intel 和 AMD 处理器的 Windows 电脑。
- **Lyricod-0.5.10-windows-arm64-setup.exe**：适用于 ARM 架构的 Windows 电脑。
- **Lyricod-0.5.10-windows-x64.zip / Lyricod-0.5.10-windows-arm64.zip**：免安装版本，解压后运行 `Lyricod.exe`，并确保 `app` 文件夹与其位于同一目录。

更新时会保留现有设置和已缓存的歌词。Lyricod 支持应用内更新。

如果从免安装版切换到安装版，且此前启用了开机启动，请在「设置 > 通用」中关闭后重新开启。

**系统要求**：Windows 10 1809 或更新版本。音乐律动条和 Lyricod Glass 的液态效果需要 Windows 11；在 Windows 10 上，Lyricod Glass 会使用清透玻璃效果。独立录屏会话的窗口排除功能需要 Windows 11 Build 26100 或更新版本，并取决于系统运行时接口是否可用。

Lyricod 目前尚未进行代码签名，首次运行时 Windows 可能显示安全提示。

This update looks for lyrics on the platform you're listening on first, and keeps its translation when the word-by-word lyrics come from the other platform.

### What's changed

- **Your platform first**: When playing in NetEase Cloud Music or QQ Music, Lyricod now looks for lyrics on that platform first. Other players still start with NetEase Cloud Music.
- **Word-by-word lyrics with translations**: If one platform only has line-synced lyrics and the other has the same song word by word, Lyricod now shows the word-by-word lyrics with the first platform's translation, instead of choosing one or the other. Songs you've played before keep their cached lyrics; choose **Search again** under Settings > Lyrics > Current song to update them.
- **Diagnostics**: When the translation comes from the other platform, Settings > About > Diagnostics shows where it came from.

### Download

- **Lyricod-0.5.10-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.5.10-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.5.10-windows-x64.zip / Lyricod-0.5.10-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
