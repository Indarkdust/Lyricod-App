Fixes since 0.1.1.

- Credit lines (作词, 作曲 …) are recognised in NetEase's word-by-word lyrics and in plain-text lyrics too, so Show credits hides them, and an upload that's only credits isn't taken for lyrics.
- Lyrics with word timing that leave the start of a line untimed no longer lose those first words.
- A song's own timing adjustment now applies when QQ Music corrects the song's length a moment after it starts.

### Download

- **Lyricod-0.1.2-windows-x64.zip**: most Windows PCs (Intel and AMD).
- **Lyricod-0.1.2-windows-arm64.zip**: Arm PCs (Snapdragon, Copilot+ PCs).

Unzip it anywhere and run `Lyricod.exe` in the Lyricod folder; Lyricod lives in the notification area. To update, quit Lyricod first, then replace its folder with the new one: your settings and saved lyrics are kept. It needs Windows 10 (version 1809) or later; the island's bars follow the music on Windows 11. Lyricod isn't signed yet, so Windows may warn the first time: choose **More info › Run anyway**.

Lyrics use the MiSans font by Xiaomi (its licence is in `Assets/Fonts`).
