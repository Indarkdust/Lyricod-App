The same Lyricod for Windows, in about half the download, steadier when it quits, and better at finding word-by-word lyrics.

- The download is about half the size of 0.1.0's. It leaves out the parts of the Windows App SDK and .NET that Lyricod doesn't use, such as AI, machine learning, search and widgets.
- Lyricod starts a little faster.
- Quit and Restart (for example after changing the language) no longer crash on the way out when the island is showing.
- Saved lyrics show straight away. When NetEase has a song only line by line, Lyricod looks for QQ Music's word-by-word copy in the background, and tries again the next day if QQ Music couldn't be reached (0.1.0 gave up on that song for good).
- An unexpected reply from a lyrics site no longer leaves a song without lyrics.

### Download

- **Lyricod-0.1.1-windows-x64.zip**: most Windows PCs (Intel and AMD).
- **Lyricod-0.1.1-windows-arm64.zip**: Arm PCs (Snapdragon, Copilot+ PCs).

Unzip it anywhere and run `Lyricod.exe` in the Lyricod folder; Lyricod lives in the notification area. To update from 0.1.0, quit Lyricod first, then replace its folder with the new one: your settings and saved lyrics are kept. It needs Windows 10 (version 1809) or later; the island's bars follow the music on Windows 11. Lyricod isn't signed yet, so Windows may warn the first time: choose **More info › Run anyway**.

Lyrics use the MiSans font by Xiaomi (its licence is in `Assets/Fonts`).
