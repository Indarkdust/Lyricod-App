A safer update for the zip version.

- **Updates only count once Lyricod is fully up.** When the zip version updates itself, the old version is now kept until the new one has started following your player, not just shown its windows; if anything goes wrong before that, the old version is put back and started, and you're told the update didn't finish.
- **The old version can't go missing during an update.** If the update can't check on the new version, it doesn't go ahead, and the new version no longer tidies away the old one while the update is still deciding.

### Download

- **Lyricod-0.4.1-windows-x64-setup.exe**: the installer, for most Windows PCs (Intel and AMD).
- **Lyricod-0.4.1-windows-arm64-setup.exe**: the installer, for Arm PCs (Snapdragon, Copilot+ PCs).
- **Lyricod-0.4.1-windows-x64.zip** and **Lyricod-0.4.1-windows-arm64.zip**: the same, without installing. Unzip it anywhere and run `Lyricod.exe` in the Lyricod folder, keeping the `app` folder next to it.

Lyricod lives in the notification area. Your settings and saved lyrics are kept whichever you choose. From 0.3.1 on, Lyricod updates itself from Settings › About or the tray panel; to update from 0.3.0 or earlier, quit Lyricod, then replace its whole folder with the new one, or run the installer. If you move from the zip to the installer and had Open at login on, turn it off and on again in Settings › General. It needs Windows 10 (version 1809) or later; the island's bars follow the music on Windows 11. Lyricod isn't signed yet, so Windows may warn the first time: choose **More info › Run anyway**.
