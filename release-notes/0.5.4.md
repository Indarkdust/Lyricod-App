# Lyricod 0.5.4

This update fixes romaji for Japanese lyrics.

- **Romaji**: Japanese lyrics now show romaji when pronunciation is on. On some PCs, Windows' Japanese analyser wouldn't work for Lyricod, so romaji never appeared.
- **Notices**: the downloads now include Lyricod's `NOTICE` file, and the third-party notices mention BetterNCM and InfLink-rs, which NetEase Cloud Music sync downloads only when you choose to install it.

### Download

- **Lyricod-0.5.4-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.4-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.4-windows-x64.zip** / **Lyricod-0.5.4-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
