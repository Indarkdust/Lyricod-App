An installer, update checks and a tidier island.

- **Installer.** Lyricod now comes as a setup program too: it installs for you alone (no administrator needed), adds Lyricod to the Start menu, and can be removed in Settings › Apps like any other app. Installing over an older copy, or uninstalling, quits Lyricod first.
- **A tidier download.** The zip now holds just `Lyricod.exe`, a short README and an `app` folder, instead of hundreds of files and a folder for every Windows language. Only the English and Chinese language files are left, so the download is smaller too.
- **Update checks.** Lyricod looks for a new version once a day and shows it in Settings › About and in the tray panel. You can turn this off, or check now, in Settings › About.
- **Diagnostics.** Settings › About has a Copy Diagnostics button with the details worth sending with a problem report (your user name is left out).
- **The island fits each line.** It's as wide as the line being sung (or the translation under it, if that's wider) instead of the song's longest line, and the second row only appears under lines that have something there.
- **Island size options.** Settings › Lyricod Island › Size (small to extra large) and Maximum width, for screens where the island looks too small or too big.
- **Tray panel.** Its right side is no longer cut off, and it sits just above the taskbar.

### Download

- **Lyricod-0.2.0-windows-x64-setup.exe**: the installer, for most Windows PCs (Intel and AMD).
- **Lyricod-0.2.0-windows-arm64-setup.exe**: the installer, for Arm PCs (Snapdragon, Copilot+ PCs).
- **Lyricod-0.2.0-windows-x64.zip** and **Lyricod-0.2.0-windows-arm64.zip**: the same, without installing. Unzip it anywhere and run `Lyricod.exe` in the Lyricod folder, keeping the `app` folder next to it.

Lyricod lives in the notification area. Your settings and saved lyrics are kept whichever you choose. To update the zip version, quit Lyricod, then replace its whole folder with the new one. If you move from the zip to the installer and had Open at login on, turn it off and on again in Settings › General. It needs Windows 10 (version 1809) or later; the island's bars follow the music on Windows 11. Lyricod isn't signed yet, so Windows may warn the first time: choose **More info › Run anyway**.

Lyrics use the MiSans font by Xiaomi (its licence is in `app/Assets/Fonts`).
