Lyricod Glass 多了一种更像真玻璃的立体效果「拟真」😮，以及优化了性能表现(真的)。

从 0.6.0 或 0.6.1 更新时，只需下载有变化的文件。(应用内!)

### 更新内容

- **拟真**：Lyricod Glass 新增立体效果「拟真」：上下边缘的高光会提亮背后的画面，两侧带有一道暗线，边缘的折射也更圆、更深。
  - 新安装时默认使用。已经在用 Lyricod Glass 的话会保持原来的样子，可以在「设置 > 歌词岛 > Lyricod Glass 设置 > 立体效果」中选择。
- **玻璃色调**：新增「浅色」。
- **性能优化**：
  - Lyricod Glass：歌词岛后面的画面没有变化时，会(大幅)减少截取屏幕的次数，应该能降低 GPU 占用；切换到其他窗口时会立刻跟上。
  - 歌词窗口：背景不是「流动的专辑封面」时，占用降低一半左右。
  - 屏幕关闭后，歌词岛的音量条和音频读取会暂停，屏幕亮起后恢复。
- **进度条**：
  - 歌词窗口的进度条现在会跟随封面颜色：大封面下用封面的颜色，窄布局下淡一些；封面没有明显颜色时为白色。
  - 在歌词窗口内把鼠标停在进度条上，也会显示那个位置对应的时间了。仅限可以拖动进度的播放器。
- **桌面歌词**：放在屏幕顶部附近时，变高（比如调大字号）不会再超出屏幕顶端、把歌词切掉，而是从顶端往下展开。
- **检查更新**：检查失败时会说明原因（比如当前网络的 GitHub 查询次数已达上限，或无法连接），给出可以重试的时间，并附上发布页面的链接。
- **界面文字**：重新整理了Lyricod中的文字。
- **设置窗口**：最大化时，部分页面不再偏到右边、被截掉一截。

更新时会保留现有设置和已缓存的歌词。Lyricod 支持应用内更新。

Lyricod Glass gets a 3D effect that looks more like real glass, **Lifelike**, plus better performance.

From 0.6.0 or 0.6.1, Lyricod downloads only the files that changed. (In-app!)

### What's changed

- **Lifelike**: A new 3D effect for Lyricod Glass. Light along the top and bottom brightens what shows through, with a dark line down the sides, and the edges bend what's behind them in a rounder, deeper way.
  - It's the default for new installs. If you already use Lyricod Glass, yours stays as it is; choose it under Settings > Lyricod Island > Lyricod Glass options > 3D effect.
- **Glass tint**: A new **Light** tint.
- **Performance**:
  - Lyricod Glass: while nothing behind the island changes, it captures the screen (much) less often, which should take less GPU; it catches up at once when you switch to another window.
  - Lyrics window: uses about half as much with a background other than **Moving album art**.
  - With the screen off, the island's audio bars and audio reading pause, and start again when it comes back on.
- **Progress bar**:
  - The lyrics window's progress bar now takes the cover's colour: full under the big cover, paler in the narrow layout, and white when a cover has no clear colour.
  - Resting the pointer on the lyrics window's progress bar now shows the time at that point too. Only for players that can be seeked.
- **Desktop lyrics**: Parked near the top of a screen, the lyrics no longer grow past its top edge and get cut off (for example when you make the font bigger); they grow downward from there.
- **Update checks**: A check that fails now says why (such as GitHub's hourly limit for your network, or no connection), when to try again, and links the release page.
- **Wording**: Texts in Lyricod were reworded to be clearer and more consistent.
- **Settings window**: When maximised, some pages no longer slide to the right and get cut off.

### Download

- **Lyricod-0.7.0-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.7.0-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.7.0-windows-x64.zip / Lyricod-0.7.0-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.
- **patch-0.6.0-to-0.7.0-….zip / patch-0.6.1-to-0.7.0-….zip**: Used by in-app updates (one each for x64 and arm64), which download them automatically. No need to (and please don't, not from here 😭) download them yourself.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
