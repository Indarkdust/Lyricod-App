# Lyricod 0.5.0

This update adds a floating mode and the Lyricod Glass theme for Lyricod Island, and shows the island by default.

- **Floating island**: choose Floating in Settings > Lyricod Island > Island mode. The island gets rounded corners on all sides. Unlock it to drag it anywhere on your screen, then lock it again in Settings or the tray menu. Near the edge of the screen, it grows away from the edge so long lines and the mini player stay visible.
- **Lyricod Glass**: a new see-through theme for the island. Choose it in Settings > Lyricod Island > Theme. By default it uses the liquid effect, which adds a slight blur and refracted edges to what's behind the island, with light along its edge. You can also choose Clear or Frosted, and adjust the transparency, tint, blur and refraction. While the liquid effect is on, the island won't appear in screenshots, recordings or screen sharing.
- **Hover by direction**: the option is now called "Hide or expand based on entry direction". Moving onto the island from any side hides it. To open the mini player, move sideways across the island, then down (a floating island also opens if you move up).
- **Simpler island settings**: floating and Lyricod Glass options only show when you use them, and text and animation settings are folded away until you expand them.
- **Island on by default**: new installs show Lyricod Island. If you already use Lyricod, your current setting is kept.

### Download

- **Lyricod-0.5.0-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.0-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.0-windows-x64.zip** / **Lyricod-0.5.0-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
