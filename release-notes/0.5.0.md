# Lyricod 0.5.0

This update adds a floating mode for Lyricod Island and shows the island by default.

- **Floating island**: choose Floating in Settings > Lyricod Island > Island mode. The island gets rounded corners on all sides. Unlock it to drag it anywhere on your screen, then lock it again in Settings or the tray menu. Near the edge of the screen, it grows away from the edge so long lines and the mini player stay visible.
- **Hover by direction**: the option is now called "Hide or expand based on entry direction". A floating island also hides when the pointer enters from above.
- **Island on by default**: new installs show Lyricod Island. If you already use Lyricod, your current setting is kept.

### Download

- **Lyricod-0.5.0-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.0-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.0-windows-x64.zip** / **Lyricod-0.5.0-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars require Windows 11. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
