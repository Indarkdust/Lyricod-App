The first release of Lyricod for Windows: synced lyrics for whatever's playing, as in the macOS app.

- Follows the player in Windows' media controls: Spotify, Apple Music, QQ Music, NetEase Cloud Music, music sites in a browser and most others.
- Lyrics from NetEase Cloud Music, QQ Music (word by word) and LRCLIB, with translations and pronunciation (pinyin, romaji, romanised Korean).
- Desktop lyrics, Lyricod Island at the top of the screen with bars that follow the music, and a lyrics window over the album art.
- A tray panel like the Mac's menu-bar panel, Choose Lyrics, per-song timing, global shortcuts, and English or Simplified Chinese.

### Download

- **Lyricod-0.1.0-windows-x64.zip**: most Windows PCs (Intel and AMD).
- **Lyricod-0.1.0-windows-arm64.zip**: Arm PCs (Snapdragon, Copilot+ PCs).

Unzip it anywhere and run `Lyricod.exe` in the Lyricod folder; Lyricod lives in the notification area. It needs Windows 10 (version 1809) or later; the island's bars follow the music on Windows 11. Lyricod isn't signed yet, so Windows may warn the first time: choose **More info › Run anyway**.

Lyrics use the MiSans font by Xiaomi (its licence is in `Assets/Fonts`).
