# Lyricod 0.4.0

This update adds new ways to use and customize Lyricod Island, along with fixes for lyrics and updates.

- **Hover behaviour**: a new option hides the island when the pointer enters from below and expands it into the mini player when entering from either side.
- **Island colours**: choose a lyric and audio-bar colour instead of using colours from the album artwork. This setting is separate from desktop lyric colours.
- **Mini player**: the small cover and audio bars fade out when the island expands, so the artwork only appears once.
- **Browser searches**: a new option controls whether Lyricod looks for lyrics when media plays in browsers or other non-music apps. It is enabled by default and can be disabled in Settings > Lyrics.
- **NetEase Cloud Music**: added a guide link when the player doesn't provide playback position and the lyrics may drift.
- **Portable updates**: the previous version is retained until the updated app starts, allowing recovery if the update fails.
- **Other fixes**: song-specific lyric choices and timing are preserved when a player corrects the track duration; malformed timestamps and unusually large lyric downloads are handled more safely.

The download packages now include third-party licence texts and notices in `app\licenses`.

### Download

- **Lyricod-0.4.0-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.4.0-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.4.0-windows-x64.zip** / **Lyricod-0.4.0-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars require Windows 11. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
