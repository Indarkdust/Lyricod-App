# Lyricod 0.4.2

This update rewrites Lyricod's English and Chinese text so it's clearer and more consistent.

- Settings, the tray panel, Choose Lyrics and update messages use simpler, more direct wording.
- The NetEase Cloud Music help link in the tray panel opens the updated guide.

### Download

- **Lyricod-0.4.2-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.4.2-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.4.2-windows-x64.zip** / **Lyricod-0.4.2-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars require Windows 11. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
