# Lyricod 0.5.13

这次更新带来了新的应用图标，Lyricod Glass 的立体效果可以在「明亮」和「柔和」之间选择，并新增了实验性的「平滑扫过」✨

### 更新内容

- **新图标**：Lyricod 换上了新图标。音符更醒目，正在唱的那一行一眼就能看出来，在托盘和任务栏这样的小尺寸下也更清楚。
- **立体效果**：「设置 > 歌词岛 > Lyricod Glass 设置 > 立体效果」现在可以选择「关」「明亮」或「柔和」。「明亮」就是之前的效果，边缘有清晰的高光，在内容丰富的背景上更有厚度感；新的「柔和」高光较淡，背光一侧带有阴影，在纯色背景上边缘依然清楚。悬浮歌词岛下方的阴影也会随之变化。之前开启了立体效果的，更新后保持「明亮」。
- **平滑扫过（实验性）**：「设置 > 关于 > 实验性功能」新增「平滑扫过」。长音后面紧跟短音时，已唱颜色会移动得更均匀，不会先慢后突然加快；短音可能稍微提前亮起，颜色边缘也更柔和。「按词分隔罗马音」也移到了这里，诊断信息会显示开启了哪些实验性功能。
- **网易云音乐歌词同步**：已在网易云音乐 3.1.43 上测试。

### 下载

- **Lyricod-0.5.13-windows-x64-setup.exe**：适用于大多数 Intel 和 AMD 处理器的 Windows 电脑。
- **Lyricod-0.5.13-windows-arm64-setup.exe**：适用于 ARM 架构的 Windows 电脑。
- **Lyricod-0.5.13-windows-x64.zip / Lyricod-0.5.13-windows-arm64.zip**：免安装版本，解压后运行 `Lyricod.exe`，并确保 `app` 文件夹与其位于同一目录。

更新时会保留现有设置和已缓存的歌词。Lyricod 支持应用内更新。

如果从免安装版切换到安装版，且此前启用了开机启动，请在「设置 > 通用」中关闭后重新开启。

**系统要求**：Windows 10 1809 或更新版本。音乐律动条和 Lyricod Glass 的液态效果需要 Windows 11；在 Windows 10 上，Lyricod Glass 会使用清透玻璃效果。独立录屏会话的窗口排除功能需要 Windows 11 Build 26100 或更新版本，并取决于系统运行时接口是否可用。

Lyricod 目前尚未进行代码签名，首次运行时 Windows 可能显示安全提示。

This update brings a new app icon, a choice between a **Bright** and a **Soft** 3D effect for Lyricod Glass, and an experimental **Smooth sweep**.

### What's changed

- **New icon**: Lyricod has a new icon. The note is bolder and the line being sung stands out at a glance, so it reads clearly even at small sizes in the tray and on the taskbar.
- **3D effect**: Settings > Lyricod Island > Lyricod Glass options > 3D effect now offers Off, Bright or Soft. Bright is the look you had before, a clear light along the edge that gives the glass thickness over a busy background. The new Soft look has a fainter light with shade on the side away from it, which keeps the edge visible over a plain background. The shadow under a floating island follows your choice. If you had the 3D effect on, it stays Bright after updating.
- **Smooth sweep (experimental)**: A new switch under Settings > About > Experimental. When a long note is followed by quick ones, the sung colour moves more evenly instead of crawling and then rushing. Quick words may light up slightly early, and the colour's edge is softer. Romaji by word has moved here too, and Diagnostics now lists which experimental features are on.
- **NetEase Cloud Music sync**: Tested with NetEase Cloud Music 3.1.43.

### Download

- **Lyricod-0.5.13-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.5.13-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.5.13-windows-x64.zip / Lyricod-0.5.13-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
