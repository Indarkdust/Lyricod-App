# Lyricod 0.5.9

This update keeps the desktop lyrics on top, adds a three-line layout, and makes long lines break neatly and stay put while they're sung.

- **Desktop lyrics stay on top**: another app's always-on-top window or Show Desktop (Win+D) no longer hides the desktop lyrics or the island. The app you're using, its menus and the taskbar still come first.
- **Pronunciation and translation**: the desktop lyrics can show both under the line, in Settings > Desktop lyrics > Under the line.
- **Line breaks**: long lines break into even rows at spaces, after punctuation and between words, never leaving a single character on a row or starting one with "」" or "、". In the lyrics window a line keeps the same rows while it's sung, so it no longer jumps as it lights up.
- **Lyrics window**: moving on to the next line, the lines below follow one after another, and the moving album art drifts and breathes a little more.
- **Romaji by word (experimental)**: Settings > Lyrics can space Japanese romaji by word instead of by syllable, using Windows' Japanese reader. It's off by default.
- **Diagnostics**: Settings > About > Diagnostics shows how many lines have a translation and a pronunciation, and where the pronunciation came from.

### Download

- **Lyricod-0.5.9-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.9-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.9-windows-x64.zip** / **Lyricod-0.5.9-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Session-specific capture exclusion requires Windows 11 build 26100 or newer and runtime interface availability. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
