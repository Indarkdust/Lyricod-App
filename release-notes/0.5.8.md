# Lyricod 0.5.8

This update brings the font you choose to all of Lyricod, opens the tray panel from a right-click too, and tidies Settings.

- **Font**: the font you choose, now **Font** in Settings > General, is used across Lyricod: Settings, the tray panel, buttons and song titles, not only lyrics. Lyrics change to a new font right away; the rest of Lyricod changes after a restart, which Settings offers. The default keeps Windows' own font.
- **Tray icon**: right-clicking the icon opens the same panel as clicking it, instead of the old short menu.
- **Locks in the tray panel**: the Desktop lyrics and Lyricod Island tiles each have a lock toggle in the corner. Desktop lyrics can be locked while they're showing, and the island's lock appears when it floats.
- **Settings**: the **Start Lyricod with Windows** switch lines up with the other controls, and Settings > About > Diagnostics is grouped into Lyricod, the player, the song and its lyrics, so it's easier to read.

### Download

- **Lyricod-0.5.8-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.8-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.8-windows-x64.zip** / **Lyricod-0.5.8-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Session-specific capture exclusion requires Windows 11 build 26100 or newer and runtime interface availability. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
