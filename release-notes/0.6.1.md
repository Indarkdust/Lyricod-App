### 更新内容

- **继续播放**：现在歌词应该会从暂停的位置继续播放动画。
- **进度预览**：在迷你播放器内把鼠标停在进度条上，会显示那个位置对应的时间。仅限可以拖动进度的播放器。
- **桌面歌词位置**：调整字号后，桌面歌词的底边保持不动；重启后也不会再慢慢偏移。
- **更省资源**：歌词岛或桌面歌词隐藏时不再更新歌词，重新显示时立刻跟上。
- **平滑扫过（实验性）**：不占时长的词（比如 QQ 音乐歌词里的空格）出现在停顿前时，会按时亮起，不再等到停顿结束。
- **稳定性**：某首歌的单独设置（比如手动选择的歌词）保存失败时，Lyricod 不会再退出。
- **感谢**：以上大部分问题由 @Adenine-AGCT 发现并修复（#4）。

Small fixes: lyrics no longer jump ahead when you resume, the desktop lyrics stop wandering off, and the mini player's progress bar can now preview a time.

It's also the first release you can update to incrementally: from 0.6.0, Lyricod downloads only the files that changed.

### What's changed

- **Resuming**: Some players report the old position again when you resume after a pause, which made the lyrics skip ahead by the time spent paused. Lyricod now carries on from where you paused.
- **Progress preview**: In the mini player, rest the pointer on the progress bar to see the time at that point. Only for players that let you seek.
- **Desktop lyrics position**: Changing the font size keeps the desktop lyrics' bottom edge in place, and they no longer drift a little after each restart.
- **Lighter on resources**: When the island or the desktop lyrics are hidden, they stop updating, and catch up as soon as they're shown again.
- **Smooth sweep (experimental)**: A word with no length of its own (such as a space in QQ Music lyrics) right before a pause now lights up on time instead of waiting for the pause to end.
- **Stability**: If saving a song's own settings (such as lyrics you chose) fails, Lyricod no longer closes.
- **Thanks**: Most of these were found and fixed by @Adenine-AGCT (#4).

### Download

- **Lyricod-0.6.1-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.6.1-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.6.1-windows-x64.zip / Lyricod-0.6.1-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.
- **patch-0.6.0-to-0.6.1-windows-x64.zip / patch-0.6.0-to-0.6.1-windows-arm64.zip**: Used by in-app updates, which download them automatically. No need to download them yourself.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
