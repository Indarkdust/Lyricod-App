优化了性能表现 ~~以及修复了一些已知问题(?)~~

从 0.6.0 或 0.6.1 更新时，只需下载有变化的文件。(应用内!)

### 更新内容

- **性能优化**：
  - Lyricod Glass：歌词岛后面的画面没有变化时，会(大幅)减少截取屏幕的次数，应该能降低GPU 占用。
  - 歌词窗口：背景不是「流动的专辑封面」时，占用降低一半左右。
  - 屏幕关闭后，歌词岛的音量条和音频读取会暂停，屏幕亮起后恢复。
- **进度条**：歌词窗口的进度条现在会跟随封面颜色：大封面下用封面的颜色，窄布局下淡一些；封面没有明显颜色时为白色。
- **桌面歌词**：放在屏幕顶部附近时，变高（比如调大字号）不会再超出屏幕顶端、把歌词切掉，而是从顶端往下展开。

Mostly about using less power: Lyricod Glass, the lyrics window and the tray panel use less CPU and GPU, and the desktop lyrics no longer slip past the top of the screen.

From 0.6.0 or 0.6.1, Lyricod downloads only the files that changed.

### What's changed

- **Lighter on resources**:
  - Lyricod Glass: while nothing behind the island changes, it captures the screen less often, which takes much less GPU.
  - Lyrics window: uses about half as much with a background other than **Moving album art**, and less still while minimised.
  - With the screen off, the island's audio bars and audio reading pause, and start again when it comes back on.
  - The tray panel is a little lighter while it's open.
- **Progress bar**: The lyrics window's progress bar now takes the cover's colour: full under the big cover, paler in the narrow layout, and white when a cover has no clear colour.
- **Desktop lyrics**: Parked near the top of a screen, the lyrics no longer grow past its top edge and get cut off (for example when you make the font bigger); they grow downward from there.
- **Settings**: If the settings file holds a value this version can't read (say, after going back from a newer version), only that setting returns to its default and the rest are kept. Before, all of them were reset.
- **Screen readers**: Buttons that show only an icon, the tray panel's tiles and the expandable sections in Settings now have names that Narrator and other screen readers can read.

### Download

- **Lyricod-0.6.2-windows-x64-setup.exe**: Installer for most Windows PCs with Intel or AMD processors.
- **Lyricod-0.6.2-windows-arm64-setup.exe**: Installer for ARM-based Windows PCs.
- **Lyricod-0.6.2-windows-x64.zip / Lyricod-0.6.2-windows-arm64.zip**: Portable versions. Extract the archive and run `Lyricod.exe`, keeping the `app` folder beside it.
- **patch-0.6.0-to-0.6.2-….zip / patch-0.6.1-to-0.6.2-….zip**: Used by in-app updates (one each for x64 and arm64), which download them automatically. No need to download them yourself.

Existing settings and cached lyrics are preserved when updating. Lyricod supports in-app updates.

If you switch from the portable version to the installer and previously enabled startup, turn it off and back on under Settings > General.

**System requirements**: Windows 10 version 1809 or newer. Music-reactive bars and the Lyricod Glass liquid effect require Windows 11; on Windows 10, Lyricod Glass uses clear glass. Session-specific capture exclusion requires Windows 11 build 26100 or newer and an available runtime interface.

Lyricod is currently unsigned, so Windows may display a security warning when you first run it.
