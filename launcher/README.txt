Run Lyricod.exe. Keep the app folder next to it.
Lyricod updates itself from Settings › About. You can also close it and replace the whole Lyricod folder.
You can use the installer instead of this portable zip.

运行 Lyricod.exe，并将 app 文件夹保留在它旁边。
Lyricod 可以在“设置 › 关于”中自行更新；也可以先退出 Lyricod，再替换整个 Lyricod 文件夹。
也可以选择安装程序，而不使用此便携版 zip。
