# Lyricod for Windows

[English](README.md) | 简体中文

Windows 上的逐字同步歌词：显示在屏幕顶部的歌词岛、悬浮在桌面上，或在单独的窗口中。原生应用，支持 x64 和 ARM64 电脑，界面提供英文和简体中文。

## 显示方式

- **歌词岛**：屏幕顶部的一个黑色胶囊，显示封面、按专辑颜色逐字划过的当前歌词，以及随音乐跳动的六根音量条。它会贴合每一行歌词的长度，可以在下方显示翻译、音译或下一句，过长的歌词会按时间分段显示。指针悬停时，可以展开为迷你播放器、隐藏以便使用下方的内容，或不做任何操作；也可以按方向决定：从下方移入时隐藏，从两侧移入时展开。音乐停止片刻后它会淡出，再次播放时出现。
- **桌面歌词**：浮在所有应用之上、可以点击穿透的一到两行歌词。在设置中解锁后即可拖动位置。
- **歌词窗口**：整首歌词在专辑封面上滚动，点击任意一行即可跳转。窗口较宽或全屏（F11）时，封面和播放控件显示在歌词旁边，字号随窗口变大；指针静止时控件会淡出。
- **托盘面板**：点击通知区域中的 Lyricod 图标，可以看到当前歌曲和播放控件、歌词岛和桌面歌词的开关，以及这首歌的歌词来源和时间调整。
- **音译**：在每行歌词下方显示罗马音、韩文罗马字或拼音。日语优先使用歌词来源自带的罗马音；装有日语输入法时，也可以由 Windows 的日语读音功能生成。
- **全局快捷键**：在任何应用中播放/暂停、切歌、显示或隐藏各个视图，以及微调当前歌曲的歌词时间。默认不设置，需要在 设置 › 快捷键 中录制。

## 支持的播放器

Lyricod 会跟随任何出现在 Windows 媒体控件（音量滑块上方的媒体面板）中的播放器：Spotify、QQ 音乐、网易云音乐、Apple Music、浏览器等。它会跟随正在播放的那一个，也可以在 设置 › 通用 中指定。浏览器中播放的视频不会被当作歌曲，除非它明显是一首歌，例如官方音乐视频。

大多数播放器会告诉 Windows 当前播放到哪里，所以即使来回拖动进度，歌词也能保持同步；对于不提供进度的播放器，Lyricod 会从歌曲开始时自行计时。网易云音乐就是这样，请看下一节。

## 网易云音乐

网易云音乐会告诉 Windows 正在播放什么，但不会告诉它播放到哪里，所以 Lyricod 只能自行计时，拖动进度或暂停后歌词可能会不同步；这时托盘面板中会出现指向本节的链接。免费插件 **InfLink-rs** 可以让网易云音乐提供准确的播放进度，以及完整尺寸的专辑封面。它运行在网易云音乐的插件加载器 **BetterNCM** 中。两者都由其他作者开发，并非 Lyricod 的一部分，而且会改变网易云音乐的运行方式，请在你愿意的情况下再安装。

1. 退出网易云音乐。从 [BetterNCM Installer 的发布页面](https://github.com/std-microblock/BetterNCM-Installer/releases/latest)下载 `betterncm_installer.exe`，运行它并安装 BetterNCM。
2. 打开网易云音乐，在 BetterNCM 的插件商店中找到并安装 **InfLink-rs**。也可以从[它的发布页面](https://github.com/apoint123/inflink-rs/releases/latest)下载 `InfLink-rs.plugin`，复制到 `C:\betterncm\plugins` 文件夹。
3. 重启网易云音乐，并在 InfLink-rs 的设置中打开 SMTC 选项。

Lyricod 会自动识别：托盘面板中的链接会消失，设置 › 关于 › 诊断信息中也会显示播放器提供了播放进度。InfLink-rs 在网易云音乐 3.1.20 至 3.1.41（以及 2.10.13）上测试过。如果网易云音乐更新后出现问题，请更新插件，或者删除网易云音乐安装文件夹中的 `msimg32.dll` 来移除 BetterNCM。不要同时安装旧版 InfLink 和 InfLink-rs。

## 歌词

来自**网易云音乐**、**QQ 音乐**（包括逐字歌词，以及两者的翻译和罗马音）和 **[LRCLIB](https://lrclib.net)**，找到的歌词会保存在你的电脑上。

如果某首歌的歌词不对，打开**选择歌词**（在托盘面板、歌词窗口或设置中）：它会同时搜索这三个来源，可以先预览再选择。Lyricod 会记住你为这首歌做的选择和时间调整，即使清除了已保存的歌词也不会丢失。

## 设置

- **通用**：开机时启动、动画帧率、语言、跟随哪个播放器
- **桌面歌词**：显示和锁定、位置、字号、已唱颜色、歌词下方显示的内容
- **歌词岛**：是否显示、指针悬停时的操作、按专辑封面为歌词着色或自选颜色、暂停时隐藏、音量条随音乐跳动、歌词下方显示的内容；样式（大小、最大宽度、字重、已唱歌词和换行的效果）
- **歌词窗口**：背景、字号、翻译、音译、居中显示、模糊、已唱歌词效果、自动隐藏控件
- **歌词**：歌词字体、是否为浏览器和其他应用查找歌词、所有歌曲和本歌曲的时间调整、音译及其语言、词曲作者信息、当前歌曲的歌词来源、已保存的歌词
- **快捷键**：播放控制、三个视图和时间调整的全局快捷键
- **关于**：版本、更新、可复制到问题反馈中的诊断信息、致谢

## 隐私

- **音量条随音乐跳动**只通过 Windows 的音频接口监听 Lyricod 正在跟随的播放器，不会录制、保存或发送任何内容。可以在 设置 › 歌词岛 中关闭。
- 为了查找歌词，Lyricod 会把歌曲的标题、歌手和时长发送给网易云音乐、QQ 音乐和 LRCLIB。这也包括在浏览器或其他非音乐播放器中播放的内容（例如视频的标题和频道名），Lyricod 需要借此判断它是不是歌曲。如果只想为音乐播放器查找歌词，请在 设置 › 歌词 中关闭“为浏览器和其他应用查找歌词”。除此之外，不会发送任何关于你观看或浏览内容的信息。
- 每天会向 GitHub 检查一次是否有新版本，可以在 设置 › 关于 中关闭。

## 系统要求

- Windows 10（1809 版）或更高版本，x64 或 ARM64
- 音量条随音乐跳动需要 Windows 11（在 Windows 10 上音量条会自行跳动）

## 安装

从本仓库的 Releases 下载：

- **Lyricod-X.Y.Z-windows-x64-setup.exe** 适用于大多数电脑（Intel 和 AMD），**…-arm64-setup.exe** 适用于 Arm 电脑（骁龙、Copilot+ PC）。只为当前用户安装，不需要管理员权限，并会添加到“开始”菜单。
- **Lyricod-X.Y.Z-windows-x64.zip** / **…-arm64.zip** 无需安装：解压到任意位置，运行 Lyricod 文件夹中的 `Lyricod.exe`，并保持 `app` 文件夹在它旁边。

Lyricod 还没有签名，所以第一次运行时 Windows 可能会提示风险：选择 **更多信息 › 仍要运行** 即可。Lyricod 运行后位于通知区域。

Lyricod 每天检查一次新版本（可在 设置 › 关于 中关闭）。有新版本时，在 设置 › 关于 中选择**下载并安装**，或点击托盘面板中的更新链接：Lyricod 会下载并校验新版本，然后重启完成更新，安装版和 zip 版都可以。也可以手动更新：运行新的安装程序，或者退出 Lyricod 后替换整个 Lyricod 文件夹。设置和已保存的歌词都在 `%LOCALAPPDATA%\Lyricod` 中，两种方式都会保留。可以在 设置 › 应用 中卸载；卸载不会删除这个文件夹，如需彻底清除，请手动删除它。

## 字体

歌词默认使用微软雅黑。在 设置 › 歌词 中可以改用电脑上安装的任意字体，也可以选择推荐的小米 MiSans：拉丁字母、中文和日文采用同一套设计，所以一行歌词和它的翻译风格一致。Lyricod 不包含 MiSans；选择它时会从小米官网下载（约 15 MB），并按照小米的许可协议使用。
